# La Paliativista

Sitio estatico profesional para Diana Echavarria (La Paliativista).

## Vista local

Desde esta carpeta:

```bash
python3 -m http.server 8080
```

Abrir `http://localhost:8080`.

## Estructura

- `index.html` - pagina principal.
- `assets/` - estilos, scripts e imagenes publicas optimizadas.
- `fotos laplaiativista/` - fotos fuente locales, ignoradas por git.
